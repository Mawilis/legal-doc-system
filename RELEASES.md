# Releases

No production release tag is created by this GitHub governance-plane campaign.
Existing historical tags are preserved as **legacy release markers** for
auditability; they describe prior repository states and do not override current
governance contracts.

Before a future release, verify the repository integrity guard, public-status
drift check, relevant Python certification, tenant boundaries, and Kennel EOS
financial ownership. A passing static check is not a live deployment claim.
