# Security

WILSY OS treats tenant scope, principal identity, authorization decisions, and
financial state as governed evidence. Report suspected vulnerabilities
privately; never publish credentials, personal data, tenant identifiers, or
payment information in issues.

Security controls are fail-closed. Missing authority, malformed identity,
cross-tenant scope, and unavailable canonical repositories must not become
success. Static or unit checks are not live infrastructure certification.

Kennel EOS exclusively owns financial execution. No documentation,
intelligence, or client surface can authorize or settle a transaction.
